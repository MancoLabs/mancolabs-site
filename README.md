# mancolabs-site

Marketing site for **Manco Labs LLC**, a software and web development studio based in Shreveport, LA.

---

## Overview

A single-page marketing site covering services, selected work, background, and a contact form. Built with plain HTML and CSS — no framework, no build step.

## Tech Stack

| Layer | Choice |
|---|---|
| Markup | HTML5 |
| Styles | CSS3 (external stylesheet) |
| Fonts | Inter, DM Sans via Google Fonts |
| Form | Web3Forms |
| Hosting | Cloudflare Pages — auto-deploys on push to `main` |

